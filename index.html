자동 판정 기준
• 자리 이탈: 얼굴이 약 2.5초 이상 감지되지 않으면 자동 일시정지하고, 돌아오면 약 0.9초 확인 후 자동 재개합니다.
• 졸음 의심: 카메라를 켤 때 개인별 눈 크기를 보정한 뒤, 고개를 숙여도 양쪽 눈이 개인 기준의 약 62% 이하로 닫힌 상태가 약 2.2초 지속될 때 판정합니다. 판정 즉시 자동 일시정지합니다.
• 고개 돌림: 얼굴 방향이 약 2.5초 크게 벗어나면 자동 일시정지하고, 정면으로 돌아오면 자동 재개합니다.
• 자동 일시정지 중에는 순공시간이 증가하지 않습니다. 짧은 깜빡임과 순간적인 움직임은 무시합니다.
실행 문제 해결
1. iPad라면 이 파일을 '파일 앱에서 직접 열기'보다 웹페이지 주소(HTTPS)로 여는 방식을 권장합니다.
2. 카메라 권한을 거부했다면 브라우저의 사이트 설정에서 카메라 권한을 허용하세요.
3. AI 엔진은 처음 한 번 모델을 내려받기 때문에 인터넷 연결이 필요합니다.
4. 이 페이지를 HTTP가 아닌 HTTPS 또는 localhost에서 실행해야 카메라 접근이 가능합니다.
